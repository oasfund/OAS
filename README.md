# 🏦 OAS MANAGEMENT SYSTEM

## Open Amount Sinking Fund Management System

Version: 2.0 Foundation

---

## PROJECT OVERVIEW

The OAS Management System is a browser-based Loan and Membership Management System designed for the Open Amount Sinking Fund Program.

Current storage uses Local Storage.

Future versions will support:

- Google Sheets
- Google Drive Backup
- Cloud Database
- Multi-user Login
- QR Payments
- SMS Notifications
- Email Notifications
